# シンスレッズ インプット統合メモ（@ren_ai_nerve適用版）

- 注意: 数字・成果目安はすべて講座側の主張であり保証値ではない。仕様・料金・案件条件は現行情報で確認する。実績の捏造、嘘の希少性は禁止（セット自体の明記事項）。

## 全体の思想（3行）
1. Threads運用は「集客→教育・ファン化→マネタイズ」を順番ではなく並行で回す。目的はフォロワー数そのものではなく、商品が売れる状態。
2. 購入理由の中心は発信者への好意より商品の有益性。
3. 伸びるかどうかは投稿テクニック以前に、アカウント設計（ジャンル・ポジション・コンセプト）で大方決まる。

## むぎの運用指標（最重要）
- 狙う指標は「いいね」ではなく **詳細タップとプロフィールアクセス**。成否はほぼ1行目で決まる。
- フェーズ判定（レンの現在地）: フォロワー約100前後＝フェーズ1（〜100）。講座の基準では「量でバズを狙う（1日5〜10投稿）」段階。※現行の7週間テストは1日3本で設計済み。この乖離は最大の論点として残す（下記「未決事項」）。100〜1000はAI活用＋ファン化・教育を混ぜ1日3投稿程度＋アフィリ開始、1000〜は自作商品と高単価へ。

## 指示書01 アカウント設計（適用チェック済み）
- ジャンル選定は収益モデルで判断（アフィリ中心=単価5,000円以上×母数／低単価=1万円以上の商品が成立する興味分野／高単価=専門性と深い悩み）。母数が小さく収益手段もないジャンルは除外。
- 市場リサーチは競合10件以上・手作業なら10時間相当が基準。収集項目は指示書02の標準項目で統一し、取れない項目は「未確認」。
- ベンチマークは2件（運用全体1件／投稿スタイル1件）。
- キャラ設計7要素: イメージキャラ／価値観／実績（事実のみ）／性格タイプ／口調／過去の経験／理想のゴール。
- コンセプト5ステップ: 競合把握→誰のどんな悩みか（絞りすぎない。絞りすぎは母数を殺す）→手段→未来→一言に集約（具体性か意外性を必ず入れる）。「何の人か」が第三者に伝わらなければ作り直し。
- プロフィール型: 名前＝名前＋肩書き、IDは短く先頭に名前。本文は行ごとに役割（価値提示→学べること→実績→行動喚起）。必須3要素=発信内容／実績／フォローするメリット。※レンの現行プロフィールはバイブル式4行で刷新済み。講座式（6行前後）との差は未決事項。
- 完璧なポジションが作れなくても、考え抜いたら開始可。運用しながら寄せる。

## 指示書02 リサーチ（むぎの標準手順にする）
- 収集と一次分析はAIエージェントが担い、人間は調査設計・判定・感覚養成。シートは記録用ではなくAIへの出力様式。
- 依頼時は5点を必ず指定: 対象／範囲（競合10件以上、投稿サンプル目安100件、期間、媒体）／収集項目／出力様式（表・固定）／禁止事項（推測補完・出典のない数字）。
- 標準収集項目: アカウント名・ID・ジャンル／フォロワー数（取得日つき）／開始時期（初投稿日＋連携IG参加時期から推定し根拠併記、「推定」と明記）／コンセプト・ポジショニング／プロフィール構成とマネタイズ導線／発信パターン／代表的な伸びた投稿／強みと弱み（所見として分離）。
- ルートA フィード流し見（人間の感覚養成、十数分で数百件、プロフィールまで往復、他ジャンルの伸びを自ジャンルへ転用してストック）。
- ルートB Threads内は検索が弱い前提で上位タブ＋プロフィールタブの2経路。バズ投稿のコメント欄＝次のネタの宝庫。
- ルートC 他SNSからの先取りが差別化の本命。Xは「キーワード＋min_faves:100」＋除外フィルタ（-filter:images / -filter:native_video / -filter:replies / -filter:retweets）＋from: 指定。YouTube・TikTokから専門知識と生活寄りの悩みを仕入れる。
- 分析の型: 有益/無益の判定／テクニック6種のどれか／フックの型／フォロー転換の仕掛け／自アカウントへの転用可能性。一次判定はAI、最終判定は人間。
- 成果物: 競合表／ネタストック表／型リスト／競合マップ／未確認リスト。

## 指示書03 投稿作成（今後の原稿はこの型で作る）
- 王道3部構成: フック（冒頭1〜3行、一番言いたいこと＋具体的な数字・手段・対象）→本編（PREP法: 主張→理由→具体例→再主張）→エンド（ベネフィット＋CTAで理由と利益を添える）。
- 本文にリンクを置かない（必要ならリプライへ）。狙う指標は詳細タップ/プロフィールアクセス。
- 読みやすさ: 指示語を減らし名詞で書く／数字は半角／絵文字は基本なし〜要点に少量／一文は短く語尾を反復しない／漢字とひらがなのバランス／不要な接続詞・前置きを削る（引き算）／箇条書きは情報の圧縮に。
- テクニック6種（組み合わせて使う）: ①一次情報（自分の経験・検証・発見。一般情報の寄せ集め不可）②常識破壊（論理一貫が条件、根拠のない逆張り禁止）③権威性（自分の実績が本命、他者は引用のみ）④ターゲット限定（冒頭で対象明示）⑤大量（箇条書きで詰め込む。保存・コメント狙い、連発で鮮度低下）⑥再現性（手順・具体策で「自分もできる」、フォロー転換高）。＋ワード選びの新規感（既視感のある単語を新鮮に言い換える）。
- 型バリエーション: タップ投稿3種（会話形式で解決を一部伏せる／課題言語化＋解決策と効果／途中で区切り続きをコメント欄）※流行依存、常用しすぎない。引用投稿は全投稿の2割まで（持ち上げる／口コミ共有／補足や持論）。認知拡大（一般的な悩み・願望を入口に自ジャンルへ接続、入口と中身を無関係にしない）。販売・アフィリは新PASONA（問題→親近感→解決策→提案→限定→行動）、日常投稿で常用しない。
- 頻度の目安: フェーズ1は1日5〜10／ファン化重視は長文1日1を核／IG送客重視は1日3〜5／Threads単体は1日10が基準・最低5。原則「質を落とさず出せる最大量」、伸び始めたら頻度を落とさない。
- PDCA: 投稿前に基準値（表示・いいねの目標線）を置く→未達なら要因分解（冒頭／ターゲット／ネタ需要／言葉の知名度／見やすさ／導線）→一度に全部変えず仮説1つずつ→テーマのシリーズ化を検討。勝因分析も断定しない。
- NG: 単体で意味が通らない冒頭／対象者が分からない始まり／体験談だけで読者利益なし／説明を本文に詰め込む／過度な断定と根拠のない数値／本文への直リンク。
- 成果物の形式: 投稿文（完成形）＋狙いの明示（型・テクニック・狙う指標）＋（依頼があれば）代替フック案3つ。

## 指示書04 ファン化
- ファン化＝同ジャンル他者より優先して見てもらう状態。ただし商品の有用性が前提で、ファン化だけでは売れない。
- 購入者の多くは反応しないサイレントファン。反応数だけで価値を測らない。ファンは実績のすごさより行動・思考への共感と尊敬で生まれる。
- 戦略は「増やす」より先に「減らさない」。禁止: 内輪向け発信／読者に利益のない私的投稿の多用（全体の5%以内）／反応層だけに合わせる／人格否定・攻撃（共通の敵は「考え方」だけが対象）。
- フォーマット7種: 信念（週1程度）／自己開示（読者が自分と重ねられる部分）／認知的共感（状況・感情を先回り言語化）／共通の敵（考え方のみ）／失敗の開示（2〜3週に1回、前向きに締める）／自信（断言＋根拠）／代弁（言語化できない本音を言葉にする）。
- 文化形成: アクションへの見返りを明示する／「いいねは次の投稿の燃料」という意味づけを繰り返す／何度でもアクションしてよい空気を作る。
- 集客投稿と混ぜて回す（フェーズ2以降で比重を上げる）。ファン化だけに寄せると新規リーチが止まる。
- 成果物: 完成文（フォーマット明示）＋狙う心理（共感／尊敬／一体感）＋減らす行為チェック。

## 指示書05 教育と販売
- 教育＝価値観を変え「望んで買う」状態を作ること。対象の大半は無関心・無知層で、悩み自覚層へ引き上げるのが仕事。「教えている感」を出さず有益投稿や体験談に自然に混ぜる。効きやすいのはクローズドな場（LINE等）、Threadsは入口と日常接点。
- 教育6種: 信頼（実績を数字で小出し／先に与える／他者の声。誇張禁止）／目的（理想の未来を具体的な生活像で。軸は時間・お金・人間関係）／問題（障害の特定→複数切り口で指摘→放置した最悪の未来。不安の煽りすぎ注意）／手段（問題の教育とセットで「原因が○○だから、やるべきは○○」）／行動（損失回避／行動を褒める／必要行動量の明示）／投資（機会損失／自分の投資姿／リターン提示／アンカリング）。
- 販売への接続は教育が進んだ層にのみ。新PASONAかローンチで。有益情報は出し惜しみしない（商品と角度をずらせば内容の2〜3割が投稿に出るのは可）。教育は弱い商品を売る技術ではない。

## 指示書06 ローンチ（全体要約＋P8から要点のみ）
- 本格実施の目安は5,000〜10,000円以上の商品。4フェーズ: 4週間前=需要確認（反応が平均の1.5倍以上か）→2〜4週間前=教育・匂わせ・告知→2週間前〜当日=教育＋進捗共有＋強み提示（網羅性・希少性・再現性）＋カウントダウン→当日（準備8割、通常の3〜5倍の投稿、開始直後3時間が勝負、販売数を具体的に報告、下書き5〜10本、ライブ最低1回）。嘘の値上げ予告・先着枠は厳禁。

## 指示書07 アフィリエイト
- フロー: ASP登録→ジャンルに合う案件選び→投稿→成約管理。初期目標はフォロワー100人、そこまでは集客優先。
- 案件基準: 悩みに直結／単価1件5,000円以上を優先（低単価は複数購入の構造がある場合のみ）／一次情報を語れる案件だけ（語れない案件は紹介しない）／ASPは分野で得意が違うので現行条件を必ず確認。
- 投稿の型: 本文=一次情報・体験・感想（メリット列挙だけは売れない）、リプライ=リンク＋おすすめ理由。本文にリンクを貼らない。販売寄りは新PASONA。広告明示など法令・規約は現行ルール要確認。
- 導線は開設1週間以内に固定投稿＋プロフィールリンクへ設置し、通常投稿から固定投稿への誘導を毎日複数切り口で。導線ができてから集客の量を増やす（順序を逆にしない）。
- レベニューシェアは上位選択肢（他者の高単価商品を紹介し固定額または売上割合で紹介料）。自社商品が作れるならそちらが最終的に最も収益性が高い。
- 成果物: 案件選定シート＋紹介投稿（本文＋リプライ）＋導線設置チェックリスト。

## 指示書08 AI活用（むぎ自身の運用）
- AIは型の再現装置。決めるのは「伸びる投稿を見分ける目」と生成後の人間の修正。
- 標準フロー: 集める（バズ投稿／自分らしい投稿／ファン化投稿の3種）→テンプレート化（分析プロンプトの骨格=役割／入力形式／指示／出力形式、出力はテンプレ名・特徴・構成要素（詳細と例）の階層）→プロジェクト化（目的別にテンプレートを使い分け）→生成（テーマは具体的に。生成後は一次情報の追加・自分らしさ・読みやすさチェック）。
- 生成は1回1投稿（まとめても最大3〜5件）。良いプロンプトと成果物は蓄積して再利用。冒頭だけ人間が書き続きをAI、も有効。
- 縛りの強さ: 強い=型の安定量産（模倣リスク注意）、弱い=新規性。目的で調整。
- 人間らしさ: 文末の揺らぎ／短文（15字以内）と長文（20字以上）の混在／比喩は回数制限／口語の粗さを残す／絵文字・区切り線などの禁止指定／冒頭の一言はリストで別管理。
- プロンプト集P1〜P13の対応: P1設計／P2競合整理／P3ネタ出し（20個、半分は認知拡大、抽象ネタ禁止）／P4投稿作成／P5添削／P6ファン化／P7教育プラン／P8ローンチ／P9アフィリ／P10分析・テンプレート化／P11テンプレート生成／P12週次PDCA／P13競合AIリサーチ依頼。今後の各作業は対応する型を使う。

## むぎの今後の運用（このインプットで変わること）
1. Threads原稿を作る前に「狙う指標（詳細タップ/プロフィールアクセス）・使うテクニック・型」を決め、原稿に狙いを併記する。
2. 週次振り返りはP12の形式（基準値との比較→冒頭・ターゲット・ネタ・言葉・見やすさ・導線で分解→仮説は確信度つき→改善は1つずつ検証できる形で最大5つ）で行う。
3. 競合・ネタのリサーチは指示書02/P13の標準項目と禁止事項（推測補完なし・未確認は未確認）で実行する。
4. ファン化フォーマット7種をローテーションに組み込み、「減らす行為」チェックを通す。サイレント層を前提に、反応数だけで投稿を切り捨てない。
5. 効能の断定をしない等、従来のレンの表現ルール（神経系ブリーフの言い換え等）はこの教材より優先する。教材側の「断言」系テクニックも、ヘルスケア領域では根拠のある範囲に限る。

## 未決事項（勝手に変えない。ユーザーの判断待ち）
- A. 投稿頻度: 現行テストは1日3本。講座のフェーズ1基準は1日5〜10本。切り替えると公式予約の枠（上限25件）と原稿量が変わるため、判断が必要。
- B. プロフィール形式: 現行はバイブル式4行。講座式は役割分担の6行前後＋必須3要素チェック。当面は現行を維持し、P1形式で検査だけ行う手もある。
- C. 収益導線: アフィリ開始はフォロワー100到達後が講座の初期目標。固定投稿・プロフィールリンクへの導線設置はその時点で設計する。
