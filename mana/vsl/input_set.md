## 1. 全体要約

プログラムの中身は「リストマーケティング一式を、順番に作り切る」ことに尽きる。商品を1つ決める→その商品に興味がある人をLINE等に集める→登録後に教育配信で価値を伝える→配信文と販売ページをAIで作る→販売日から逆算してローンチする→数字を分けて振り返り、次の商品（高単価）につなげる、の6章構成。各章に成果物が指定されているのが特徴で、特典として第1期・第2期のアーカイブ、スキル一式、テンプレート類が付く。

## 2. ノウハウ（章別・手順として抽出）

### 第1章 商品設計
- 売る商品は1つに絞る（全部やろうとして全部中途半端が典型的な失敗）。
- 中身（教材・動画本数）から作り始めない。先に決めるのは「誰の・どんな悩みを・何がどう変わるか・どこまで提供／サポートするか・特典と価格」。
- 顧客が既に試して止まっている場所を調べる。競合リサーチにもAIを使う。
- 既存商品がある人は見直しから。成果物: 商品企画書、販売までの全体マップ。

### 第2章 集客・リスト作り
- 無料特典は販売商品に合わせて作る（特典と商品がずれると、買わない人だけが集まる）。
- 投稿に役割を持たせる: 集客（見つけてもらう）／教育（必要性に気づいてもらう）／販売（行動してもらう）。大半の人は集客しかやっていない。
- AIで役割分担した投稿を30本作り、どこからLINE登録につなげるかまで決める。
- プロフィールと固定投稿までを導線として整える。成果物: 登録特典、登録ページ、役割付き投稿30本、プロフィール、固定投稿。

### 第3章 リスト教育
- 登録直後から商品案内までの「教育シナリオ」を先に全部作っておく（毎回「今日は何を送ろう」で止まらないため）。
- 伝える順番: 今どこでつまずいているか→解決に何が必要か→自分の商品で何を手伝えるか→どんな人に合っているか。
- 商品説明は特徴の列挙ではなく「その内容で自分の何が変わるか」まで翻訳する。
- 材料は顧客が実際に使っている言葉（不安、試して失敗した理由）を調べること。成果物: 登録直後の配信、案内までの教育シナリオ。

### 第4章 配信文・販売ページをAIで作る
- AIに渡すのは「誰に向けた文章か／何を伝えたいか／読んだ後に何をしてほしいか」の3点。下書きをAIに作らせ、自分の経験と商品の具体を入れて仕上げる。
- 丸投げ禁止の確認3点: 顧客の悩みを取り違えていないか／商品の内容と違うことを書いていないか／自分が普段使わない言葉になっていないか。
- この手順自体をマニュアル化し、次の配信・次の商品でも使い回す。成果物: 教育配信文、動画台本、記事原稿、販売ページ、プロンプト集、AI運用マニュアル、自動化フロー。

### 第5章 ローンチ
- 販売日を決めて逆算: 事前告知→詳細提示→募集開始→購入前の疑問に答える配信→締切案内、までを日付入りで先に作る。
- 講座・コンサル型は個別相談／DMの流れも型にする（困りごとを聞く→手伝えることを伝える→疑問に答える→申込案内）。「リンクを貼って興味があればどうぞ」で終わらせない。
- 成果物: ローンチ手順書、配信スケジュール、告知・募集・締切の案内文、営業トーク集。

### 第6章 振り返りと次の販売
- 数字を分けて見る: LINE登録数／どの配信からリンクが押されたか／販売ページ閲覧数／申込数。売れなかった原因を「商品が悪い」で一括りにしない（例: ページを見てもらえていないなら直す場所は商品より前）。
- 買わなかった人への配信継続（タイミングの問題の人がいる前提）と、購入者フォロー。
- 低単価の購入者が「やってみて困ったこと」から高単価商品（サポート付き等）を設計する。成果物: 振り返りシート、改善案、販売後の配信計画、高単価商品の企画書。

### 特典（動画で提示された範囲）
- 第1期・第2期のアーカイブ全部（講義・ワーク・Q&A）。第1期の扱い範囲: 価値設計、Threads／X投稿と運用、LINEリスト集客、6つの教育、note／Brain販売ページ、ベネフィット変換、AI運用。第2期: ドメイン知識と逆算、言語化されていない悩みの発見、AI投稿の下書きと予約・自動化、プロンプト／コンテキスト／スキル／ハーネスの使い分け、バイブコーディング入門。
- スキル一式（投稿作成、スライド式ツリー投稿、X記事 等）、有料コンテンツ、ChatGPT／Codexセミナーアーカイブ、動画生成AIの教科書、ハーネス・コンテキスト設計の図解資料（44枚と説明）、テンプレート・ワークシート類（マネタイズ設計書、オファー設計シート、投稿設計テンプレート、販売ページの型、AI運用マニュアル、プロンプト集）。

## 3. 既存のまな式セット（MKドライブ 11_まな式.md）との関係

- 大半は既習と一致する: オファーから作る商品設計、投稿の役割付与（集客・教育・販売）、6つの教育、痛みの言語化、決まりファイル＋実績台帳でAIを制御する方式、ローンチ部品をAI指示の連鎖で作る工程（企画03）、数字の分離と振り返り。
- 今回のVSLで新しく明確になった点は3つだけ:
  1. 6章を「成果物つきの直線工程」としてパッケージ化したこと（章ごとに作る物が固定されている）。
  2. 第3章（教育シナリオの設計）と第4章（AIで文章を作る手順）を別ステップに分けたこと。
  3. 第6章で「登録／クリック／閲覧／申込」の数字分離と、買わなかった人への継続配信、高単価企画書までを正式な最終ステップに入れたこと。
- つまり新規ノウハウの追加は小さく、本質は既存セットの「販売まで一気通貫のパッケージ化」である。

## 4. @ren_ai_nerve への転用（実践アウトプット）

今すぐ使えるもの（フォロワー規模が小さく、商品もLINEリストもまだ無い段階）:
- 投稿の役割タグ: 現在のThreads 4形式（ツリー／質問／問いかけ／共感）に、集客／教育／受け皿への誘導の役割を1本ごとに付けて管理する。販売の役割は今は「プロフィールと固定投稿（受け皿案A）へ流す」ことに置き換える。
- 第6章の数字分離: フォロー転換を「プロフィール表示のフォロワー数／プロフィールアクセス／詳細タップ」で分けて見る運用は、既存のThreads判定基準と一致するので継続でよい。
- 第4章の確認3点は、むぎの制作チェックにそのまま足せる（悩みの取り違え＝視聴者の困りごととズレていないか／内容の相違＝AI.mdの根拠から外れていないか／言葉の相違＝リリ／レンの普段の言葉か）。健康表現のNG→OK表が常に優先。

今は使わないもの（時期尚早）:
- 商品設計・リスト教育・ローンチの各章は、売る商品と集める場所（LINE等）ができてから。フォロワー82人（Threadsプロフィール表示・11/9時点）の段階でローンチ工程を組んでも、集める母数が無い。
- 将来 ren で有料noteやミニ講座を売る段階になったら、第1章→第3章→第5章の順でこのセットをそのまま設計図にできる。

採用しないもの:
- 実績数字を使った訴求の仕方と、締切・環境論による参加圧力の型。ren は健康ジャンルで、効能を断定しない運用ルールが優先する。
