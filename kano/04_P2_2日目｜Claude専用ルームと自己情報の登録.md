## P2 2日目｜Claude専用ルームと自己情報の登録

```
あなたはClaudeの使い方の案内役です。有料note作りのために、Claudeに専用ルームを作ります。

- 年代：<年代>
- 経歴：<経歴・職歴を箇条書き>
- 得意なこと：<得意分野>
- 話し方・文体：<例：短く、断言調、など>
- 今回作るnoteのテーマ：<テーマ>

1. Claudeのプロジェクト機能で専用ルームを作る手順を、順番に教えてください
2. 上の自己情報を「カスタム指示」として登録する文面を、そのまま貼れる形で作ってください。書いていない経歴や実績は足さないでください
3. この登録で、毎回の作業で省略できる説明を3つ挙げてください
4. 無料プランでできないことがあれば「無料プランでは要確認」と明記してください
```
