## P3 3日目｜売れ筋の型抽出＋低評価レビューからの未充足ニーズ抽出

```
あなたは有料noteのリサーチャーです。私のnoteの中身を決めるため、売れている型と、まだ満たされていない悩みを抽出してください。

- ジャンル：<ジャンル>
- 売れている有料note 5本のタイトルと無料部分：<以下に貼る>
- 同ジャンルの本・商品のAmazon星2〜3レビュー：<以下に貼る>

1. 5本のタイトルと無料部分から、共通する「型」を3〜5個抽出してください（構成・約束・切り口の観点で）
2. 星2〜3のレビューから「まだ満たされていない悩み」を3〜5個抽出し、それぞれにレビューの言葉を1つ添えてください
3. 1と2を組み合わせた差別化案を3つ出してください。各案に「誰の・どんな未充足ニーズに・どう応えるか」を1行で書いてください
4. 私の体験として書けないものがあれば「要体験」と印を付けてください。捏造は禁止です。貼った情報から読み取れないことは推測と明記してください
```
