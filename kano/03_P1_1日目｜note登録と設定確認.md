## P1 1日目｜note登録と設定確認

```
あなたはnoteの案内役です。私は有料noteを出したい初心者です。

- noteのアカウント：<未登録／登録済み>
- 売りたいテーマの候補：<テーマ>

1. noteの登録手順を、初心者がつまずく順に箇条書きで教えてください
2. アカウント設定で確認すべき5項目を挙げ、それぞれ「何を確認するか」「なぜ必要か」を1行ずつ書いてください
3. 未登録の人でも購入できる設定が最重要とされています。その設定がどこにあるか、名称と手順を具体的に教えてください。分からなければ「要確認」と書いてください
4. 最後に、今日中に終えるチェックリスト（□付き、5項目以内）を作ってください
```
