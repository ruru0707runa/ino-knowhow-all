# SNS運用代行くん｜使い方（最初に読む）

ご参加ありがとうございます。

「SNS運用代行くん」は、3ヶ月連続1億突破・SNSのみ累計20億のエヌイチのSNSチームの進め方をもとに作った、SNS運用を担当するAI社員です。
投稿の企画30本 → 台本 → サムネの文字 → 月の報告書 → 営業の提案書まで、1人で受け持ちます。

## このフォルダに入っているもの

| ファイル | 何か |
| --- | --- |
| `SNS運用代行くん.zip` | **これをダウンロードしてください。** AI社員の本体（フォルダ一式） |
| `エヌイチ式 SNS運用管理シート（AI社員の作業場）` | AI社員と一緒に使う管理シート（Googleスプレッドシート） |
| `ClaudeCodeセットアップガイド` | Claude Codeをまだ入れていない方向けの導入ガイドへのリンク |
| `README（セットアップ手順）.md` | zipの中に入っているセットアップ手順の中身確認用 |
| `CLAUDE.md（AI社員の役割定義）.md` | zipの中に入っているファイルの中身確認用 |
| `memory_account-profile（記入シート）.md` | zipの中に入っているアカウント情報の記入シート |

zipの中身が気になる方のために、主要ファイルをそのまま置いています。
**使うだけならzipだけダウンロードすればOKです。**

## 使い方（5分）

### STEP1｜Claude Codeを入れる（まだの方）

こちらのガイドの手順で導入してください。
https://www.notion.so/36082bdc9c5b816a9930c2debcfe1408

※Claude Codeを使うには、Claudeの有料プラン（Pro以上）が必要です。

### STEP2｜zipを解凍して好きな場所に置く

デスクトップなどに置いてください。解凍すると `sns-unyou-daikou-kun` というフォルダができます。

### STEP3｜Claude Codeでそのフォルダを開く

**Claudeのデスクトップアプリを使う方**
アプリの「Code」タブを開き、入力欄の下にあるフォルダの選択で `sns-unyou-daikou-kun` フォルダを選びます。

**ターミナルを使う方**
次を実行します。

```
cd （解凍したsns-unyou-daikou-kunフォルダのパス）
claude
```

※パス入力が面倒なら、`cd ` と打ってからフォルダをターミナルにドラッグ＆ドロップすると自動で入ります。

### STEP4｜動作確認

`あなたの役割を教えて` と話しかけてください。
SNS運用代行くんとして役割を説明すれば成功です。

### STEP5｜管理シートを自分用にコピーする

Googleにログインした状態で、このフォルダにある「エヌイチ式 SNS運用管理シート（AI社員の作業場）」を開き、自分のドライブにコピー（ファイル → コピーを作成）してください。
https://docs.google.com/spreadsheets/d/19BpshjBXbOdxFmxA1IQPi9zeC9kdtA5udhvEEYlaVCE/edit

最初は、SNS運用代行くんが出した企画や報告の表を、このシートに貼り付けて使ってください。
数字はシートからコピーして、SNS運用代行くんに貼れば読み取ります。
※AIにシートへ直接書き込ませるには、別にGoogleとつなぐ設定が必要です。

## ⚠️ 解凍したのに中身が少なく見える方へ

skillは `.claude/skills/` という**ドットから始まる隠しフォルダ**に入っています。
Macのfinderは標準でこれを非表示にするため「中身が空」に見えますが、**正常です**。

見たい場合はfinderで `command + shift + .`（コマンド＋シフト＋ピリオド）を押してください。もう一度押すと元に戻ります。
