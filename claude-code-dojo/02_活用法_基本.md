# 二 活用法・基本

## 基本の型

どの活用法にも効く3つです。最初にここだけ覚えておくと、あとが楽になります。

### 1 ルールを覚えさせる（CLAUDE.md）

ジャンル・読む人・書き方を1枚のメモにしておくと、毎回の説明がいらなくなります。Claude Codeは作業の前に必ずこれを読みます。

プロンプト（〇〇を自分の内容に書き換えて送る）

```
このフォルダに CLAUDE.md を作って、次のルールを書いて。

# Threadsの投稿ルール

## 誰に向けて

- ジャンルは〇〇

- 読む人は〇〇（例：AIを仕事で使い始めた30代の会社員）

## 1行目

- 読む人が「自分のことだ」とすぐ分かる言葉を入れる

- 結論を最初に書く。前置きはしない

- 数字か、具体的な名前・場面を入れる

## 本文

- 言い切る。「かもしれない」「可能性がある」は使わない

- 具体的な数字・ツール名・場面を必ず入れる

- 100〜300字。言いたいことの後に、どうでもいい説明を足さない

- 話し言葉を少し混ぜる

## 使わないもの

- ダブルクォート、太字の記号、絵文字の連発

- 「〜することができます」「〜じゃなくて〜」

- 「絶対稼げる」のようなお金の断言
```

実際に送った結果の CLAUDE.md は上記テンプレの〇〇を「ジャンルはAIの仕事での使い方／読む人はAIを仕事で使い始めた30代の会社員」に置き換えたもの。Claude Codeの返事：「CLAUDE.md を作成しました。」

### 2 会話が長くなったら、要約かリセット

1回の会話で覚えていられる量には上限があります。同じ作業を続けるなら要約、別のことを始めるならリセット。

プロンプト（要約するとき）

```
/compact 〇〇の仕様と、できたファイル名は必ず残して
```

覚えるのはこの4つ

- `/compact` **要約して続ける**（返事がずれてきたとき）
- `/clear` **リセット**（別のことを始めるとき）
- `/memory` **覚えている内容を見る**（まちがって覚えたことを直す）
- `@ファイル名` **ファイルを指定する**（「@posts.csv の3番を直して」）

### 3 スクショを渡して伝える

「この雰囲気で」は、言葉より画像のほうが早く伝わります。スクショを入力欄にドラッグして、その下に指示を書きます。

プロンプト（スクショと一緒に送る）

```
この画像の雰囲気と色使いを参考にして、自己紹介のページを作り直して。

文章と画像はそのまま使わず、私の内容で
```
