# 四 活用法・仕事

## 仕事の型

講座やサービスの準備、調べもの、ファイルの片づけに使う活用法です。

### 10 LPを1枚作る

先に構成だけ相談して、決まってからページを作らせます。参考は2〜3枚、雰囲気だけ借ります。

プロンプト（2回に分けて送る）

```
# 1回目：構成だけ相談する

〇〇（講座や商品）のLPを作りたい。まず構成を一緒に考えて。

読む人は〇〇。強みは〇〇。

# 2回目：構成が決まったら

この構成でLPを1ファイルで作って。スマホで見やすく。ブラウザで開いて見せて
```

### 11 競合を調べて、比べる表にする

URLをファイルに並べておけば、毎月同じ形のレポートが作れます。前回との違いも出してくれます。

プロンプト（competitors.txt にURLを1行ずつ書いてから送る）

```
competitors.txt のサイトを読んで、特徴・料金・強み・ターゲットを比べる表を作って。

reports/競合_今月.md に保存して。前回のレポートがあれば、変わったところも書いて
```

### 12 フォルダを一括で片づける

ファイル名をそろえる、種類ごとに分ける、といった片づけをまとめて任せます。動かす前に必ず予定を出させます。

プロンプト（最初に予定を見せてもらう）

```
このフォルダの画像を、撮った日ごとにフォルダ分けして、名前を「日付_連番」にそろえて。

動かす前に、どのファイルがどこへ行くか一覧で見せて。消すのはなし
```
