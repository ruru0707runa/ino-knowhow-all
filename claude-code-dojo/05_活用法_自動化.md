# 五 活用法・自動化

## 自動化の型

毎週同じようにやっている作業を、一言で終わるようにします。プログラムは書きません。決まったプロンプトとフォルダを用意するだけです。

### 13 投稿の予定を、カレンダーのページにする

投稿の予定を月のカレンダーにして、予定・下書き・投稿済みを色で分けます。

プロンプト（posts.csv があるフォルダで送る）

```
threads/posts.csv の投稿を、来週の月〜金に2本ずつ割り振って、

月カレンダーのページ（calendar.html）にして。

予定・下書き・投稿済みを色分けして、ブラウザで開いて見せて
```

### 14 毎週の数字を、レポートにする

Threadsの数字を表にして置いておけば、毎週同じ形で振り返れます。

プロンプト（data/ に今週の数字のCSVを置いてから送る）

```
data/ の今週のCSVを集計して、表示・いいね・伸びた投稿トップ3・先週との違いをまとめて。

伸びた理由と、来週試すことを2つずつ書いて。reports/週次_今週.md に保存して
```

### 15 いつものプロンプトを、スキルにする

毎回同じプロンプトを送っているなら、スキルにしておくと /名前 の一言で呼び出せます。作るのもClaude Codeに任せられます。

プロンプト（発信の4ステップをスキルにする）

```
発信の型の4つのプロンプト（リサーチ・型・投稿・テンプレ化）を、それぞれスキルにして。

名前は /research /kata /post /template。次からは一言で各ステップを回せるようにして
```

### 16 自分の作業の自動化を相談する

週1回以上、手順がだいたい同じ、1回30分以上。この3つがそろう作業から始めます。

プロンプト（自分の作業を書いて送る）

```
毎週〇〇という作業をしています（手順：①〇〇 ②〇〇 ③〇〇）。

これを一言で終わるようにしたいです。プロンプトとフォルダの作り方を教えて。最初の1回も試しにやって
```
