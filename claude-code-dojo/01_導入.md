# 一 導入（目安10分）

Claude Codeは、日本語で頼むと、パソコンのフォルダに本物のファイルを作ってくれるAIです。使うのはClaudeのアプリだけ。黒い画面（ターミナル）は使いません。

## まずプランを確かめる

Claude Codeは、**Pro以上の有料プラン**で使えます。無料プランでは使えません。
（公式の料金ページ：claude.com）

## やること

1. 公式のダウンロードページから、パソコン用の**Claudeのアプリ**を入れる（claude.com のダウンロードページ）
2. アプリを開いて、Claudeのアカウントで**サインイン**する
3. デスクトップに、**「claude-work」**という名前のフォルダを1つ作る
4. アプリのサイドバーの上のほうにある**「Code」タブ**を押す
5. 入力欄の下で**「Local」**を選び、フォルダのボタンから**「Open folder…」**を押して、「claude-work」を選ぶ
6. 入力欄の下の**権限モード**を**「Manual」**にする。ファイルを変える前に、毎回こちらの承認を待ってくれます
7. 下のプロンプトの〇〇を書き換えて送り、確認が出たら**「承認」**を押す

## プロンプト 最初の1枚

```
このフォルダに、自己紹介のページを1枚作って。

名前は〇〇、Threadsで〇〇について発信しています。スマホで見やすく。

できたらブラウザで開いて見せて
```

実際に送った結果：このサイトのプロンプトをそのまま送り、自己紹介ページが1枚できた（できたファイル：index.html）。

## こうなればOK

- フォルダに `index.html` ができて、ブラウザで自己紹介のページが開いた。ここまでで導入は終わりです

## うまくいかないとき

- Codeタブを押すと「アップグレード」と出る → 有料プランへの登録が必要です。料金ページから登録してから、アプリを開き直します
- 「Code」が見つからない → アプリを最新の版にします
- 英語で返ってきた → 「日本語で返答してください」と送る
- エラーが出た → エラーの文をそのまま貼って「このエラーの原因と直し方を教えて」と送る
