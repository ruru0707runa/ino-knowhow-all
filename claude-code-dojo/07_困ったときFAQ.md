# 問 困ったとき

## よくある質問

**黒い画面（ターミナル）を使わないとダメ？**
いいえ。このサイトの手順は、全部Claudeのアプリの中でできます。

**勝手にファイルを消されたりしない？**
権限モードを Manual にしておけば、ファイルを作ったり直したりする前に、必ず承認を待ちます。承認しなければ何もしません。

**何から始めればいいか分からない**
「このフォルダで、Threadsの発信に役立つことを5つ提案して」と送ると、向こうから案を出してくれます。

**返事がおかしくなってきた**
`/compact` で要約するか、`/clear` でリセットしてから頼み直します。

**作ったファイルはどこにある？**
導入で選んだ「claude-work」フォルダの中です。「今作ったファイルの場所を教えて」と聞いても答えてくれます。

**料金はいくら？**
Pro以上の有料プランで使えます。金額は公式の料金ページ（claude.com）に出ています。

**もっと詳しく知りたい**
Claude Codeの公式ドキュメント（日本語）（code.claude.com）に、アプリでの使い方がまとまっています。
