# 編 Opus 5.5・実演

## Claude Code（Opus 5.5）は、編集もできる

Claude Codeの仕事は、文章やページを書くことだけではありません。画像や動画の編集も、日本語で指示するだけでできます。下の3つは、このサイトとライブ特典を作るときに、Claude Code（モデルはOpus 5.5）が実際にやった編集です。

### 画像：背景を抜いて、ステッカーにする

別のAIで作ったキャラの画像を渡して、「背景を抜いて透明にして」と頼みました。Claude Codeがパソコンに入っている画像の機能を使って、キャラだけを切り抜いています。

プロンプト（画像の背景を抜く）

```
images/〇〇.png の背景を抜いて、透明なPNGにして。

キャラの輪郭はなるべくきれいに残して、images/cut/ に保存して
```

### 動画：スクショの連続を、倍速の動画にする

作業の様子を数秒おきに撮ったスクショを渡して、「つないで倍速の動画にして」と頼みました。いらない上の帯を切り落として、つなぎ目をなめらかにし、スマホでも再生しやすい形式で書き出しています。

プロンプト（スクショを動画にする）

```
shots/ のスクショを、ファイル名の順につないで倍速の動画にして。

1枚1秒くらいで、つなぎ目はふわっと切り替えて。上の60pxは切り落として。

スマホで再生できるmp4にして、video/ に保存して
```

### サイト：一言ずつ、作り直していく

このサイトも、Claude Codeへの一言ずつで今の形になりました。実際に送った指示と、そのとき変わったところ：

1. 「claude codeのテイストに変えて」→ 色・書体・最初の画面を、Claude Codeらしい配色に
2. 「もっと背景を派手に動かしたい」→ 背景にオーロラ、流れる格子の床、光の粒、タップで波紋
3. 「claude code道場入門とかにしよう 道場のテイストで和だね」→ 名前を変えて、障子が開く入り口、青海波の背景、稽古の札に
4. 「背景にはガッツリ動く桜とか入れて」→ 舞い散る桜と、風でゆれる枝を追加
