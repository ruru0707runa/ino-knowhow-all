# 実践アウトプット：ren / shiba への転用雛形

出典の発信4ステップを、むぎの運用（ren Instagram / ren Threads / shiba Threads）に変換した雛形。投稿・予約の実行は含まない。実行は ino の明示承認が別途必要。

## フォルダ構成の雛形

```text
research/        伸びた投稿のスクショ・コピーと、分析表（伸びた投稿.md）
templates/       型.md（5型の定義）、伸びたテンプレ.md（トップ3の穴埋めテンプレ）
threads/         posts.csv（番号, 型, 投稿文）
data/            週の数字.csv（表示, いいね, 返信, 再投稿, フォロワー純増）
reports/         週次_今週.md
```

## 制作判定への変換（この教材の使い方）

1. リサーチ：同ジャンルの伸びた投稿を最低10本集め、表示の谷で2群に分ける。1行目・型・数字・伸びた理由だけ表にする。
2. 型判定：新原稿は5型のどれに当たるかを先に名付ける。型に当たらない原稿は、1行目に「場面＋数字＋結論」のどれが欠けているかを確認してから直す。
3. 投稿作成：1テーマで型を変えて複数本作り、型ごとに反応を比べられる状態で出す。
4. テンプレ化：48時間／週次の数字でトップ3を穴埋めテンプレ化し、翌週はそこから始める。同じ型の2本目が落ちたら、型ではなくネタの場面が読者の今週から外れていないかを先に疑う。

## ren への当て方

- 型1・型4は ren Threads の1文投稿と、リールの0〜2秒フック（部位名指し／常識破壊）の型として使う。
- 型2・型3は連載・検証型（数字で見せる記録）の骨として使う。
- 字数の目安は Threads 投稿文の基準であり、リール台本へ流用するときは尺（秒数）へ換算し直す。

## shiba への当て方

- shiba の勝ち型（豆知識1文）は型1の変形として型ファイルへ登録し、自己返信の質問＋次回予告を本文の流れに組み込む。
- 週次レポートの形（トップ3・先週差分・来週試すこと2つ）を、shiba の判定日集計にそのまま使う。

## 注意

- 投稿時間の効果は出典内でも未分離（内容差と重なっている）。朝と夜で同じ型を出す比較をしてから判断する。
- 数字は講師・実演側の提示値。効果の保証として扱わない。詳細は 03 を参照。
