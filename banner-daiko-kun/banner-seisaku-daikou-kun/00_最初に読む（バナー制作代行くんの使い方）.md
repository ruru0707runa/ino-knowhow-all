# バナー制作代行くん｜使い方（最初に読む）

オープンチャットへの参加ありがとうございます。

「バナー制作代行くん」は、お手本のバナーを1枚見せると、AIがCanvaを自分で操作して、白紙から同じ形のバナーを組み立てるAI社員（スキル）です。
文字・写真・図形は別々の部品のまま残るので、できあがった後もCanvaで1文字から直せます。

## 必要なもの

- **Claude Code**（Claudeの有料プラン・Pro以上が必要です）。Codexでも使えます
- **Google Chrome と「Claude in Chrome」拡張機能**（AIがブラウザでCanvaを操作するために使います）
  https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn
- **Canvaのアカウント**（無料版で使えます。ただし写真の背景を消す機能は有料版だけなので、無料版では写真の背景が残り、見本と見た目が少し変わります）
- お手本にするバナーの画像1枚と、使いたい写真・画像

Claude Codeをまだ入れていない方は、公式の手順をご覧ください。
https://code.claude.com/docs/ja/quickstart

## 入れ方（Claude Code）

1. このzipを解凍します。`banner-seisaku-daikou-kun` というフォルダができます。
2. そのフォルダを、次の場所に丸ごと入れます。
   - Mac：ホームフォルダの中の `.claude/skills/`（無ければ作ります。ホームフォルダはFinderで `command + shift + H` を押すと開きます。`.claude` は隠しフォルダなので、`command + shift + .` を押すと見えます）
   - Windows：`C:\Users\（あなたのユーザー名）\.claude\skills\`
3. Chromeとつないで、Claude Codeを起動し直します。ターミナルでは次のように起動します。

```
claude --chrome
```

うまくつながらない時は、Claude Codeの中で `/chrome` と打つと、つながっているかの確認とつなぎ直しができます。

Codexを使っている方は、Codexに「このフォルダをスキルとして入れて」と頼んでください。

## 頼み方の例

```
バナー制作代行くんで、このお手本のバナー（ファイルの場所）と同じ形のバナーをCanvaで作って。
写真はこれ（ファイルの場所）、文字は「〇〇」「〇〇」にして。
```

- 「ファイルの場所」は、画像をClaude Codeの画面にドラッグすると入ります。
- Canvaには、拡張機能を入れたChromeで、あらかじめログインしておいてください。
- まずは素材を渡さずに次のように頼むと、入っている見本（電子書籍プレゼントのバナー）を作ります。これで動きを確かめるのがおすすめです。

```
バナー制作代行くんで、同梱の見本どおりにCanvaでバナーを作って
```

- 反応しない時は、`/banner-seisaku-daikou-kun` と打ってから頼んでください。
- AIが写真をCanvaに上げられない時は、先に自分でCanvaの「アップロード」に写真を入れてから頼んでください。

## 気をつけること

- お手本は「形（配置・文字の大きさの順・色の配分）」の参考に使ってください。他の人のバナーの文字・写真・ロゴをそのまま使って売ったり公開したりはしないでください。
- 同梱の見本の写真・本の表紙は、動作を確かめるための例です。ご自身のバナーには、ご自身の写真・画像を使ってください。
